## Задача 1: внедрить SEO-фикс — вариант 1 (статические снапшоты при erp-синке)
Реализуй именно тот план, который сам предложил как рекомендацию: генерация статических
`<title>/<meta description>/<meta og:*>/<link canonical>/<script type="application/ld+json">`
для каждой `/model/<code>` страницы, встроенная в уже существующий cron-синк
(`erp_sync_dolibarr.py`, раз в 30 мин).

Требования к результату:
- После фикса `curl -s https://srlux.uz/model/<code>` должен возвращать УНИКАЛЬНЫЙ,
  корректный title/description/JSON-LD для конкретного товара — не общий на всех страницах.
  Проверь минимум на 3 разных товарах из разных категорий.
- При этом сайт должен продолжать нормально работать как SPA — React должен корректно
  гидрироваться поверх этого HTML (не должно быть mismatch между статикой и тем, что рендерит
  React после загрузки). Проверь через curl что структура `<div id="root">...</div>` содержит
  валидный markup, который React сможет "подхватить", а не просто левый HTML.
- Не ломай существующие статические страницы (/about, /contacts, /delivery, главную) —
  у них уже есть какой-то generic SEO, оставь как есть или расширь по аналогии, если легко.
- Запусти синк вручную один раз после реализации, чтобы снапшоты сгенерировались сразу,
  не жди 30 минут.
- Это архитектурное изменение — тестируй аккуратно, с бэкапами перед правкой nginx.conf
